# Security

This project is experimental and unaudited. No version is supported for production authorization or real assets.

Do not post secrets or exploit details in a public issue. Use GitHub private vulnerability reporting if enabled on this repository, or privately contact the organization owner through an established channel. Include the affected commit, a minimal reproduction using disposable fixtures, and the expected and observed authorization boundary.

See [security boundaries](docs/security.md). Passing tests establish only the stated test evidence.
